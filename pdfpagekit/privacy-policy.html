PDF Page Kit — Privacy Policy

Last updated: October 5, 2026 · describes PDF Page Kit 1.0.0, the version on Google Play

The short version

PDF Page Kit collects nothing. The app has no internet permission, so it cannot send anything anywhere. There is no account, no server, no analytics, no advertising and no crash reporting. Your PDF files are processed on your phone and never leave it.

What the app does with your files

  • When you open a PDF, Android's file picker gives the app a copy of that one file. The app reads it in memory to merge, split, delete, extract or rotate pages.
  • The result is a new PDF written to the app's private cache only so that it can be handed to the share sheet or saved to a folder you pick. It is deleted when you start the next job.
  • The app keeps no history, no list of recent files and no copy of anything you opened. Closing the app discards everything that was not shared or saved.
  • Your original file is never modified.

Permissions

The app requests no permissions. Opening and saving files goes through Android's own file picker, which gives the app access to only the file or folder you choose, only for that action. The app does not request internet, storage, location, contacts, camera or microphone access.

Sharing and saving

If you choose Share, Android's share sheet opens and you pick where the file goes; the app we hand it to is governed by that app's own policy. If you choose Save to a folder, the file is written to the folder you select on your phone or a storage provider you have set up there.

Deleting your data

Because nothing leaves your phone and nothing is kept, there is nothing for us to delete. To clear the cache, uninstall the app or use Settings → Apps → PDF Page Kit → Storage → Clear cache. Files you shared or saved are yours to delete wherever you put them.

Children

The app collects no data from anyone, children included, and has no ads, links to other apps or ways to contact other people.

Changes

If a future version ever changes any of the above (for example by adding advertising), this page will say so before that version is released, and the date at the top will change.
