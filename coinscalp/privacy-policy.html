Coin Scalp — Privacy Policy

Last updated: October 23, 2026

Introduction

Coin Scalp ("the app") is a personal paper-signal tool published by OVC Tech (Rizwan Shoaib). A small server (Google Cloud Functions and Firebase Firestore) reads public cryptocurrency market data, applies one fixed rule, records each signal, scores it on paper and can send a push notification. The app on your phone only displays those records and lets you change alert settings.

The app never places trades, cannot access any exchange account, and never asks for exchange API keys, wallet credentials or payment details. Signals are not financial advice; the rule's own backtest shows no proven edge.

Data We Access and Store

  • Public market data — the server reads Binance USD-M perpetual futures candlesticks from Binance's public, keyless endpoints. No account, key, or personal or device identifier is sent to Binance.
  • An anonymous sign-in ID — on first launch the app signs in to Firebase Authentication anonymously. This creates a random user ID, not linked to your name, email or phone number. It is used only so that the backend shows the signals and settings to this installation and nobody else.
  • A notification token — only if you allow notifications — a Firebase Cloud Messaging registration token for this installation, stored with the anonymous ID and a timestamp so alerts can be delivered. Deny or revoke the permission and no token is sent; uninstalling the app makes the token invalid and it is deleted on the next failed delivery.
  • Your alert settings — the pairs, filters, risk limits, session and quiet-hour choices you set in the app.
  • Signal and score records — each signal (pair, prices, the candles at the time, outcome and paper result). These are market records, not personal data.

Data We Do NOT Collect

  • ❌ No name, email, phone number or contacts
  • ❌ No location
  • ❌ No advertising ID, no ads of any kind
  • ❌ No third-party analytics, crash reporting or trackers
  • ❌ No exchange API keys, wallet keys, balances, orders or payment details
  • ❌ We do not sell or share data with anyone

Service Providers

Data is stored and processed by Google Firebase (Authentication, Cloud Firestore, Cloud Functions, Cloud Messaging) in the European Union region europe-west1, under Google's terms. Market data comes from Binance's public API.

Retention and Deletion

Signal records and settings are kept while the app is in use. Clearing the app's data or uninstalling removes the local sign-in; the notification token is deleted automatically once it stops working. To have all server data deleted, email segmentbi@gmail.com.

Security

All traffic uses HTTPS. Firestore security rules allow only the first (owner) installation to read signals and change settings; the server writes with Google-managed credentials.

Children

The app is intended for adults (18+) and is not directed at children.
