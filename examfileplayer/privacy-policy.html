Exam File Player — Privacy Policy

Last updated: October 29, 2026 · describes Exam File Player 1.0.0, the version on Google Play

The short version

Exam File Player collects nothing. The app has no internet permission, so it cannot send anything anywhere. There is no account, no server, no analytics, no advertising and no crash reporting. The question files you open are read on your phone and never leave it.

What the app does with your files

  • When you open a file, Android's file picker gives the app a copy of that one file. The app reads the questions out of it in memory and then deletes that copy.
  • The questions it found (the question text, the options, the answer letter and any explanation) are saved in a small database inside the app's private storage on your phone, as a "bank", so you can practise them again later. The original file itself is not kept.
  • Text you paste is handled the same way: the questions found in it are saved; nothing else is.
  • Each round you finish is saved as a score (how many right, out of how many, and when) against its bank, so the bank screen can show your last and best result.
  • Your original file is never modified, moved or uploaded.
  • "Try the sample" uses questions written for the app; no file of yours is involved.

Permissions

The app requests no permissions. Opening a file goes through Android's own file picker, which gives the app access to only the file you choose, only for that action. The app does not request internet, storage, location, contacts, camera or microphone access.

Deleting your data

Everything the app keeps is on your phone. Delete one bank from its screen, or delete every bank and score from About → Delete all banks and scores. Uninstalling the app removes all of it. Because nothing leaves your phone, there is nothing for us to delete.

Children

The app is intended for adults preparing for professional certification and other exams. It collects no data from anyone, has no ads, no links to other apps and no way to contact other people.

Changes

If a future version ever changes any of the above (for example by adding advertising), this page will say so before that version is released, and the date at the top will change.
