Stats Helper — Privacy Policy

Last updated: October 17, 2026 · describes Stats Helper 1.0.0, the version on Google Play

The short version

Stats Helper collects nothing. The app has no internet permission, so it cannot send anything anywhere. There is no account, no server, no analytics, no advertising and no crash reporting. The numbers you type, paste or open from a file are used for the calculation on screen and are not saved.

What the app stores

  • Nothing. The app has no saved history and no settings. When you close it, the numbers you entered are gone.
  • The app turns off Android cloud backup; there is no app data to back up in any case.

Opening a CSV file

If you choose "Open CSV", Android's own file picker lets you select one file. The app reads that file once, on the phone, to pull the numbers out of it, and then deletes its temporary copy. The file picker is Android's Storage Access Framework, so the app needs no permission to read your storage and never sees any file other than the one you pick.

What the app does not do

  • It does not connect to the internet. The release build declares no INTERNET permission, so the operating system will not let it make a network request.
  • It does not request any other permission: no camera, microphone, contacts, location, storage or notifications.
  • It does not show ads, use analytics or crash reporting, or include any third-party SDK that collects data.
  • It does not ask for your name, email or any account.

Children

The app is a general-audience maths utility aimed at ages 13 and up (students, teachers and anyone checking a set of figures). It is not designed for children and collects no data from anyone.

Not advice

The app computes the statistics you ask for and shows the working. It is a teaching aid, not statistical, financial, medical or any other advice.

Changes

If a future version ever collects data (for example, if advertising is added), this page will be updated before that version is released, and the Google Play data-safety section will say so.
